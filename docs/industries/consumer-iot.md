# CRA — Consumer IoT & Connected Devices

Smart-home, wearables, connected appliances, routers, cameras — squarely in CRA scope, and
several fall into **important** classes.

## In scope
- Connected consumer devices and their companion software/firmware → full obligations by **11
  Dec 2027**, reporting from **11 Sep 2026**.
- **Routers, network management, some IoT** → **Annex III important** classes → stricter routes.

## Baseline expectations
- Secure **default** configuration (no default passwords), secure update mechanism, SBOM,
  vulnerability handling, defined support period.
- **ETSI EN 303 645** is the natural consumer-IoT security baseline to build against.

## Overlaps
- AI features (voice assistants, cameras with recognition) → **AI Act** transparency / possibly
  high-risk (companion guide).
- **GDPR** for any personal data captured.

## Sequence
Now: scope + reporting readiness. 2026–27: secure defaults, SBOM, update mechanism, support
period. 11 Dec 2027: conformity + CE marking.
