# CRA — Readiness Checklist

Each item should map to a dated artefact in your evidence store.

## Scope
- [ ] Product-in-scope register (connectivity, role, exemptions, provisional class)
- [ ] Role confirmed per product (manufacturer / importer / distributor / steward)

## Reporting readiness (11 Sep 2026)
- [ ] Detection/triage able to identify "actively exploited" and "severe"
- [ ] Named owners + on-call path that can meet a 24-hour clock
- [ ] Notification workflow drafted (24h / 72h / final report)
- [ ] Coordinated vulnerability disclosure policy + contact point
- [ ] Access/test account for the ENISA Single Reporting Platform
- [ ] Known exploited vulnerabilities remediated ahead of the deadline

## Technical baseline (toward 11 Dec 2027)
- [ ] Secure-by-design & by-default configuration
- [ ] No known exploitable vulnerabilities at release
- [ ] Access control, authentication, encryption where appropriate
- [ ] Secure update mechanism (timely, free patches)
- [ ] SBOM produced and maintained in CI/CD
- [ ] Vulnerability handling process across the support period
- [ ] Defined and communicated support period

## Conformity (11 Dec 2027)
- [ ] Product class determined (default / important I & II / critical)
- [ ] Annex VII technical documentation
- [ ] Conformity assessment for the class → CE marking → EU declaration of conformity
- [ ] Supplier contracts flow down CRA obligations; critical components prioritised

*Not legal advice — a readiness aid, not a certificate.*
